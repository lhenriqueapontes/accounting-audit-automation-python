# Citation / References

Este repositório demonstra um fluxo de automação de auditoria contábil com base em dados sintéticos. Para citar ou referenciar este projeto, utilize o seguinte formato:

**Pontes, Luiz Henrique de Azevedo. _Accounting Audit Automation Python_ (2026). Repositório GitHub: https://github.com/lhenriqueapontes/accounting-audit-automation-python.**

## Fontes e inspirações

Este projeto foi inspirado por materiais de auditoria contábil, artigos acadêmicos e exemplos de código abertos sobre:

- Implementações da lei de Benford em Python para detecção de fraudes (por exemplo, tutoriais de blogs como Real Python).
- Análise de dados com pandas e NumPy para avaliações financeiras.
- Geração de dados sintéticos usando NumPy, pandas e funções de distribuição.
